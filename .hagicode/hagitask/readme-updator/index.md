# README requirements

## Audience and focus

- Address maintainers who use this minimal Electron demo to validate multi-platform build, packaging and smoke testing for the HagiCode desktop pipeline.
- State that the demo carries no business logic.

## Required content

- Keep structure, common commands, PM2 validation page, spawn chain measurement, CI design, release environment variables, MSIX notes and optional PSF injection.
- Commands must match `package.json` and `scripts/`.

## Exclusions

- Exclude signing certificates, passwords, release secret values, tokens, internal hosts, machine-specific paths and private links.
